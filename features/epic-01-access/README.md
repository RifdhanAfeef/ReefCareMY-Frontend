# Epic 1 — Stakeholder roles, ownership and access

Add reusable Epic 1 components, hooks and types in this folder.

Primary route files:

- `app/(admin)/admin/users/page.tsx`
- `app/(admin)/admin/role-requests/page.tsx`
- `app/(coordinator)/coordinator/report-queue/page.tsx`
- `app/(coordinator)/coordinator/my-cases/page.tsx`

Authentication UI begins in `app/(auth)`. Route-group layouts demonstrate the intended navigation for each role, but the backend/session must still enforce access.
